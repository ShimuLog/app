## 1. 产品定位与设计理念

在数字化生活日益繁复的今天，个人财务管理工具正普遍面临广告信息流侵扰、信贷理财绑架以及云端隐私过度采集的困境。

拾木记账（ShimuLog）采用**本地优先（Local-First）**架构研发，以保护个人核心财务隐私为底线，融合端侧语意感知能力与传统手账排版美学。应用运行全程不依赖云端集中式数据库，无任何商业推广接入，为追求高效、纯粹与数据自主掌控的用户提供沉浸式的资产管理体验。

### 核心特性指标

- **零数据外溢**：核心数据库全生命周期驻留于设备本地沙盒，杜绝网络侧财务分析与用户画像挖掘。
- **纯粹交互环境**：全场景零开屏广告、零推广弹窗、零理财借贷入口，专注记账本质。
- **端侧智能感知**：在本地完成动账文本提取、商户名称结构化解析与分类自适应匹配。
- **严谨财务核算**：账户可用余额与流水实行代数推导联动，从数学机制上消除账目漂移。

## 4. 核心功能与技术机制解析

### 4.1 记账录入与算式键盘
- **毫秒级呼出体验**：扁平化交互层级设计，轻触记账按钮即刻呼出输入看板，三秒内完成录入。
- **内置算式解析器**：键盘原生支持连续四则混合运算，录入复杂账单无需在第三方计算器与记账应用间反复切换。
- **整型精度控制机制**：底层货币单位全链路采用最小分值（分）整型存储与运算，彻底阻断浮点数尾数误差。
- **网格自由度布局**：支持分类项的长按拖拽重排与个性化自定义扩展，自适应用户高频消费习惯。

### 4.2 动账感知与智能解析管线
- **端侧多通道捕获**：系统级通知监听、剪贴板动账信息感知与无障碍辅助多路协同，覆盖微信、支付宝及主流银行动账场景。
- **商户语意特征提取**：在本地内存中对消费文本进行结构化特征提取，精准分离交易对手、交易金额与卡号后四位。
- **模式联想与自适应映射**：内置启发式规则匹配算法，根据历史消费特征自适应绑定消费分类与结算账户，显著降低手动干预频率。
- **待审收件箱隔离机制**：自动捕获记录优先沉淀至待审区，由用户二次确认后入账，保障账目绝对清晰准确。

### 4.3 资产大盘与动态平衡推导
- **非漂移余额模型**：账户实时净值由初始设立金额与历史流水代数和实时推导生成，从底层防止账目与真实资产脱节。
- **借贷与报销独立台账**：将往来债务（借出待收/借入应还）与职场垫资独立归类，支持到期结算与状态冲平。
- **实物资产与定存日历**：设立实物黄金持仓台账与定期存单到期提醒系统，实现个人多元资产集中审视。

### 4.4 三重视觉材质渲染系统
- **经典纸韵（Classic Paper）**：漫反射暖阴影与素白卡片底色，呈现传统纸质手账的克制与温润。
- **液态玻璃（Liquid Glass）**：高斯模糊微透拟物、流光高光边缘与纵深投影，契合现代科技美学。
- **卡通波普（Comic Pop）**：2.0px 实线黑描边与零模糊偏移硬阴影，结构硬朗，具有极高的视觉辨识度。

## 5. 数据安全与隐私合规架构

拾木记账在架构设计上彻底放弃了依赖云端中心化存储的传统思路，将数据掌控权交还给用户。

| 安全控制维度 | 架构实现方案 | 用户权益效益 |
| :--- | :--- | :--- |
| **数据驻留边界** | 仅使用操作系统提供的独立应用沙盒 SQLite 数据库。 | 物理隔离网络侧窃听风险，消除云端撞库与数据外泄隐患。 |
| **网络流量隔离** | 全功能离线运行，核心流水链路零远程接口调用。 | 零设备网络流量消耗，杜绝后台隐蔽数据回传。 |
| **全量离线转存** | 支持将整库数据导出为结构化离线备份文件。 | 支持用户通过本地介质或个人受信任渠道自主迁移财务数据。 |
| **导入原子性保护** | 备份还原过程全程处于本地数据库事务锁保护之下。 | 校验元数据一致性，导入异常时自动回滚，确保历史数据零损坏。 |

## 6. 技术架构规范

- **研发框架**：基于空安全 Dart 语言与 Flutter 渲染管线，保证界面 120Hz 高刷新率跟手流畅度。
- **状态拓扑**：采用 Riverpod 单向数据流架构，实现界面组件细粒度局部重绘与解耦。
- **系统底层桥接**：深度集成 Android 原生 AlarmManager 系统定时服务、NotificationChannel 渠道级管理与开机自启恢复监听，确保记账提醒服务稳定触达。

## 7. 常见问题解答 (FAQ)

#### Q1: 拾木记账支持多设备实时云同步吗？
**答**：拾木记账的核心原则是“本地优先与绝对隐私”，因此不设中心化云服务器，亦不收集用户账户密码。多设备数据迁移通过离线数据备份与导入功能实现，用户可将备份文件自主保存到安全存储介质中。

#### Q2: 自动记账功能是否会上传我的短信或交易通知？
**答**：绝对不会。所有文本解析与商户分类提取均在设备本地内存瞬间完成，处理后即时释放，没有也不具备任何将敏感文本外发的网络通信逻辑。

#### Q3: 为什么提醒开关被关闭后需要系统设置授权？
**答**：遵循 Android 13（API 33）及以上版本的高等级权限规范，应用主动接入了原生权限状态检测机制。当系统权限被关闭时，应用会自动将开关状态同步回弹，避免在无权限状态下产生静默失败。
