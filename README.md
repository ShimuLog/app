# 拾木记账 (ShimuLog)

## ✨ 核心特性

- ⚡ **即开即记**：点开即记，三秒内完成一笔收支录入，拒绝繁琐操作与无用等待。
- 📊 **清晰图表**：月度/年度结余看板、分类支出构成与走势分析、记账活跃度热力打卡。
- 📅 **日历明细**：按日期清晰查阅每日收支明细，补记、对账一目了然。
- 💼 **资产账户**：支持现金、银行卡、电子钱包等多账户资产分类管理，实时跟踪净资产。
- 🛡️ **本地优先与隐私安全**：数据保存在本地设备，不上传云端分析，无任何营销推广与弹窗干扰。
