# 拾木记账 (ShimuLog)

## ✨ 核心亮点

- ⚡ **即开即记**：点开即记，三秒完成一笔记录，跟手顺畅，拒绝繁琐操作与等待。
- 📊 **多维图表**：收支走势、分类占比、记账活跃度热力打卡，财务收支一目了然。
- 📅 **日历视图**：按日清晰展示流水，补记、对账轻松快捷，支持农历节气显示。
- 💼 **资产台账**：现金、银行卡、电子钱包等多账户清晰分类，资产变动实时掌握。
- 🛡️ **本地优先与隐私安全**：数据完全保存在设备本地，不上传云端分析，无任何营销推广与弹窗干扰。
